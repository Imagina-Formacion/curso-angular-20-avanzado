# Sesión 2: Arquitectura Avanzada y Patrones de Estado

## Objetivos de Aprendizaje

Al finalizar esta sesión, los estudiantes serán capaces de:

- Implementar patrones avanzados de gestión de estado con Angular Signals
- Crear servicios escalables y mantenibles
- Aplicar interceptores HTTP funcionais
- Implementar guards de ruta modernos
- Diseñar arquitecturas basadas en composición

## Temarios

### Tema 1: Gestión de Estado Avanzada (90 minutos)
- Patrones de estado con Signals
- Store patterns sin librerías externas
- Composición de signals complejos
- Optimización de rendimiento

### Tema 2: Servicios y HTTP Avanzado (90 minutos)
- Arquitectura de servicios escalable
- Interceptores HTTP funcionais
- Manejo de errores centralizado
- Caché y optimización de requests

### Tema 3: Routing y Guards Modernos (60 minutos)
- Guards funcionais
- Lazy loading avanzado
- Resolvers con signals
- Navegación programática

- Conocimientos sólidos de Sesión 1
