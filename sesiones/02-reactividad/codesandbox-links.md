# 🛠️ Guía CodeSandbox - Sesión 02: Reactividad Avanzada

## 📦 Ejercicios para Crear en CodeSandbox

### 1. 🔄 Change Detection Optimizado
**Template:** Angular Standalone + TypeScript

**Características a implementar:**
- Comparación Default vs OnPush Strategy
- Performance Monitor en tiempo real
- Signals y Computed Signals
- Control Flow moderno (@if/@for/@switch)

### 2. 🎨 Directivas Custom con Signals
**Template:** Angular Standalone + TypeScript

**Características a implementar:**
- Directiva de permisos reactiva
- Auto-focus con effects
- Detector de clicks externos
- Estados de carga dinámicos

### 3. 💬 Campus Messaging Reactivo
**Template:** Angular Standalone + TypeScript

**Características a implementar:**
- Chat en tiempo real con Signals
- Sistema de notificaciones
- Gestión de conversaciones múltiples
- Mock de WebSocket para simulación

## 🎯 Instrucciones para Crear en CodeSandbox

1. **Ir a CodeSandbox.io** y crear nuevo proyecto
2. **Seleccionar template** "Angular" o "Angular Standalone"
3. **Seguir las instrucciones** de cada README de ejercicio
4. **Copiar y pegar** el código paso a paso según la guía
5. **Experimentar** con las modificaciones sugeridas

## 💡 Tips para CodeSandbox

- Usar Angular 18+ con configuración standalone
- Habilitar TypeScript strict mode
- Los cambios se reflejan automáticamente en el preview
- Puedes descargar el proyecto completo al finalizar
- Compartir el enlace del sandbox para revisión
